# Подтверждённая сетка оригинального MAP и её перевод в новую сцену

30 сентября 2026 года. Источник — публичный пакет одиночной AWPlanet Forever. Это определённый снимок данных, а не доказательство совпадения со всеми историческими онлайн-серверами Classic.

`data/canonical-map.json` сохраняет **262 144 слова ландшафта, 13 085 непустых размещений и 214 исходных типов объектов**. Исходные индексы и ID не заменены координатами старой стартовой реконструкции. В новом адаптере классифицированы 10 482 декоративных размещения, 1 571 существо, 148 NPC, 688 ресурсных объектов, 44 станка и 152 перехода. Это классификация для новой сцены и сервера; наличие перехода в данных не означает реализацию его маршрута.

Статический разбор официального `release.wasm` выполнен WABT без создания экземпляра WASM и без запуска игры. Локальные оригинальные бинарники, модели, картинки и дизассемблированный код остаются в игнорируемом `artifacts/original-client/`. В новой сцене используются самостоятельно созданные модели и материалы.

## Доказанные поля

| Поле | Основание в статическом WASM |
| --- | --- |
| Сетка 512 × 512 | `f146`, строки 5486–5495: `index = (second & 511) + ((first & 511) << 9)` |
| Первая плоскость — слова ландшафта | `f667`, строки 94310–94376: блок типа 5, смещение 8, 262 144 u32 в `g9`, затем столько же в `g159` |
| Вторая плоскость — объекты | `f377` читает `g159` по `f146`; low16 ID сопоставляется с именованным каталогом без неизвестных ссылок |
| Высота вершины | `f379`, строки 21845–21858: `(terrainWord & 15) × 0.375` |
| Номер тайла | `f381`: `(terrainWord & 65280) >>> 8` |
| Раздельное отображение двух областей | `f383`, строки 22820–22875: first coordinate `<256` и `>=256` выбирают разные половины адресного пространства |
| Препятствия и границы клеток | `f663`, строки 93737–94010: маски `0x04000000`, `0x00100000`, `0x00200000` участвуют в восьми направлениях доступности |
| Исходный model/texture ID | Парсер `f660` и отрисовка `f419`; подробности в `data/reference/object-metadata-provenance.json` |

`flagsRaw` каждой постановки — исходные верхние 16 бит объектного слова. Они сохранены целиком. **Не следует считать всё это значение поворотом, HP, этажом или ID скрипта.**

Числовые свойства существ экспортированы отдельно статическим разбором каталога: HP, уровень, дальность, восемь защитных каналов, пары типа/силы урона, радиус блуждания. HP `65535` обозначает специальное значение и не используется как боевое здоровье NPC. Радиус блуждания — самостоятельное число; ранее названный `behaviorFlags` байт не является битовой маской. Агрессивность проверена через `secondaryFlagsRaw`: `(flags & 2) && !(flags & 16)` при начальном спавне.

## Адаптер координат новой версии

Первый параметр функций оригинала соответствует **строке**, второй — **столбцу**. Поэтому новая сцена принимает:

```text
row = floor(index / 512)
column = index % 512
x = row - 256
z = column - 256
```

Отшельник Боб имеет исходный ID 285, индекс 58407, строку 114, столбец 39. В новом адаптере это `(-142, -217)`. Старое предположение `(39, 114)` описывало адрес столбец/строка и не должно использоваться как порядок игровых осей.

Центрирование на 256 — выбор новой версии. Размер клетки сохранён: 1 единица. Границы перемещения — ±255; крайние технические клетки не открыты для свободной ходьбы. Переход через шов `x=0` запрещён, пока реальные лестницы, лодки и порталы не получили маршруты. Это предотвращает обычную пешую прогулку между разными областями адресного пространства.

Начальная позиция `(-141.5, -214.5)` выбрана на проходимой соседней клетке Боба. **Это новый спавн для доступности начального диалога.** Обнаруженное в оригинальном клиенте начальное состояние `(156,66)` не подменяется этим значением в утверждениях о Classic.

`src/shared/canonical-map.ts` обеспечивает единый перевод индекса, проверку клеток/рёбер и высоту. Узлы канонического A* находятся в центрах клеток, со смещением `+0.5`: узлы на целочисленных углах могут оказаться за двумя рёбрами и ошибочно изолировать район. Новая интерполяция высоты следует тем же двум треугольникам, которые рисует `canonical-world.ts`; точное совпадение с исходной интерполяцией движения отдельно не заявляется. Сервер должен использовать общую проверку доступности; клиентский маршрут не разрешает движение или получение ресурсов сам по себе.

Независимый flood по исходным кардинальным маскам даёт **32 614 достижимых клеток из выбранного спавна Боба**, включая банкиров, торговцев и существ. Диагностика `scripts/debug-map-connectivity.mjs` сохраняет подробности и растровую схему в игнорируемый `artifacts/map-debug/`. Эксперимент со снятием рёбер только в клетках исходных Door увеличил компонент всего на одну клетку; сам экспорт карты он не меняет. Таким образом, проблема целочисленных A* узлов не устраняется произвольным открытием всех дверей.

## Отрисовка и её границы

Вся сетка загружается из `/api/map`, не встраивается в JavaScript. Земля разбита на участки 32 × 32 с отсечением камерой и удалением дальних участков из отрисовки/теней; радиус составляет 54/42/30 для high/medium/low. 12 254 рёбра стен из исходных слов отображаются через instancing. Декоративные постановки группируются по исходному типу и участку; каждый исходный тип разделяет геометрию между своими участками. Для деревьев после загрузки используется новая детальная `tree.glb`, включая постановки ресурсных деревьев. NPC используют скелетные человеческие модели, Боб — отдельную `npc-bob.glb` с Idle. Монстры используют доступные новые GLB и различные формы остальных семейств.

Цвета поверхностей, вид материалов, высота стен 2.1, уровень воды 0.72, декоративный поворот и внешний вид семейства — **новая графика**. Сохранённый номер тайла не означает совпадения исходных пикселей. Точные поля крыши, состояния дверей, поворота, порталов, скриптов магазинов и квестов ещё требуют сопоставления. Станок, NPC или монстр в исходной клетке не доказывает полную реализацию его оригинальной механики.

Щелчок по земле строит путь по клеткам и рёбрам этой карты. Персонаж и динамические объекты стоят на той же геометрии, по которой вычисляется путь. Монстр выбирается мышью с подходом до 0.9 единицы; взаимодействие с NPC — с подходом до 3.4. Каноническая скорость клиентского предсказания — ходьба 1, бег 2; бег отключается при нулевом тонусе. Сервер сохраняет право отклонить любое действие.

## Повторение экспорта

```powershell
node scripts/transform-map.mjs artifacts/original-client/webdata.data
npm run check
npx tsx --test src/client/*.test.ts
```

Экспортёр проверяет сигнатуру, версию, каталог, границы каждого блока, размер MAP, наличие каталога объектов, имена каждого размещённого ID и проходимую начальную клетку. Он не исполняет исходный клиент.
