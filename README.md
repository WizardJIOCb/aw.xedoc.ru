# AW · Возвращение на планету

Независимая фанатская реконструкция AWPlanet с новой браузерной 3D-сценой и изометрической камерой. Первая играбельная альфа разворачивается на **https://aw.xedoc.ru**, сервер **82.146.42.213** (`ssh myserver`).

Восстановлены полная сетка 512 × 512 и все 13 085 размещений публичного клиента Forever; используется собственный сервер. Полного совпадения с оригиналом пока нет. Точные границы восстановления, источники и различия версий находятся в [docs/FIDELITY.md](docs/FIDELITY.md).

## Уже работает

- Регистрация, вход, общий мир через WebSocket, другие игроки и общий чат.
- Анимированный персонаж, изометрическая камера, движение/выбор цели мышью, WASD, бег, поиск пути по исходной сетке и стенам.
- Добыча ресурсов, 285 записей игрового каталога, 135 рецептов; 1 571 существо 45 типов, 148 NPC, 688 ресурсов и 44 станка в исходных клетках.
- Профессии, параметры, PvE и ограниченный PvP, три режима боя и девять форс-режимов.
- Оружие и слоты брони, еда, добыча после боя, гибель с потерей вещей и части опыта.
- Центрированные NPC-диалоги с выбором ответов, отдельная модель и портрет Боба; банк, NPC-магазин, передача предметов, простые открытые кланы, собственное вводное задание Боба.
- Серверная проверка расстояний, скорости, требований, количества предметов и времени изготовления; атомарные сохранения, продолжение изготовления после перезапуска.

Шаг сервера 0,5 секунды подтверждён интервью автора за 2010 год. Таблица XP и ряд формул извлечены из Forever. Цены, дроп, часть эффектов и рецептов реконструированы. Наличие записи предмета в каталоге не означает восстановление каждого его особого эффекта. Передача предмета пока является подарком; двустороннего подтверждаемого обмена нет. Имена кланов пока не включают полноценное управление составом.

## Локальный запуск

Node.js 22 или новее, npm:

```powershell
npm ci
npm run dev:server
```

Во втором терминале:

```powershell
npm run dev
```

Открыть `http://127.0.0.1:5190`. API/WS: `127.0.0.1:3190`. Для единого production-сервера выполнить `npm run build`, затем `npm start`.

## Управление

WASD — движение; Shift — бег; перетаскивание ПКМ — поворот камеры; колесо — расстояние; ЛКМ по земле/мини-карте — идти к точке, по NPC — подойти и поговорить, по монстру — подойти и атаковать автоматически. E — ближайший объект; 1/пробел — атака; 2 — еда; I — инвентарь; C — ремёсла; K — персонаж; M — карта; B — общение; Enter — чат; Escape — закрыть окно.

Подойди к Бобу по кнопке задания. Добыча и торговля требуют близости. Для плавки нужен соответствующий станок; изготовление занимает указанное время. Ценные вещи можно оставить в банке перед вылазкой.

## Проверки

```powershell
npm run check
npm test
npm run build
node scripts/smoke-canonical.mjs http://127.0.0.1:3190
```

Canonical smoke создаёт случайный тестовый аккаунт, выполняет обычные HTTP/WS-действия и выходит. Он не редактирует сохранения и не телепортирует персонажей. Дальние или опасные маршруты отмечаются SKIP, результат с пропусками — PARTIAL. JSON отчёт: `artifacts/canonical-smoke/`; границы проверки: `docs/CANONICAL-QA.md`. Старый `smoke.mjs` относится к учебному району прошлой версии. Подробности браузерной проверки и публичного развёртывания — в `docs/DELIVERY.md`.

## Данные и модели

Официальный публичный пакет клиента исследуется парсером `scripts/import-reference.mjs`. `scripts/transform-map.mjs` извлекает полный MAP. Отдельный справочник `data/reference/` содержит 888 именованных объектов, исходные числовые свойства и XP-кривую, 600 слотов взаимодействий. Это не 888 предметов и не готовая копия серверной базы. `data/build-world.py` воспроизводит игровой каталог.

Курица, крыса и скорпион имеют собственные модели и три анимации; подробности — [docs/CREATURES.md](docs/CREATURES.md). Hero и Drone используют локально проверенные Quaternius CC0; дом, дерево и одежда доработаны собственным Blender-пайплайном. Лицензии и проверка анимаций — [docs/ASSETS.md](docs/ASSETS.md). Редактируемые сцены — `source-art/colony-assets.blend`, `source-art/colony-detailed.blend`, `source-art/npc-bob.blend`. Новая графика описана в [docs/GRAPHICS-ASSETS.md](docs/GRAPHICS-ASSETS.md), карта — в [docs/CANONICAL-MAP.md](docs/CANONICAL-MAP.md), портрет и prompt — в [docs/GENERATED-ART.md](docs/GENERATED-ART.md). Оригинальная графика, клиентские исполняемые файлы и пользовательские сохранения в репозиторий не включены.
