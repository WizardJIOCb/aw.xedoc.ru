# Объём полного восстановления

Пользователь хочет мир, предметы и механики AWPlanet с новой графикой. Текущая альфа — первый работающий участок этой задачи. Полнота принимается по поведению, а не по числу записей каталога.

| Следующий этап                | Критерий готовности                                                                                                                                                               |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Установить выбранную версию   | Различия Classic-руководства, Unity и Single-2024 явно разрешены; эталонный список систем зафиксирован                                                                            |
| Восстановить карту            | Расшифрованы MAP-блоки, координаты и слои; узнаваемые Фармун, Баратрон, Зерон, Сетрос и подземелья воспроизводятся по проверенным данным                                          |
| Все предметы и взаимодействия | Каждый исходный объект классифицирован; 584 активных взаимодействия разобраны по полной схеме; для всех игровых предметов известны требования, эффекты и доступный путь получения |
| Точная экономика              | Подтверждены цены, NPC-ассортимент, исходные количества рецептов, вероятности, истощение ресурсов, прочность и расход программ                                                    |
| Полный персонаж и бой         | Восстановлены XP-кривые, боевой уровень, точность/реакция, каналы защиты, урон/дальность оружия, расход боеприпасов, форс, PK, якорение опыта и иммунолайзер                      |

| Квесты и NPC                  | Подтверждённые диалоги и ветвления заменяют собственное вводное задание; реализован движок заданий и сохранение каждой стадии                                                     |
| Транспорт и перемещение       | Лодки, запрет плавания, порталы и телепортеры с исходными ограничениями боя                                                                                                       |
| Социальные системы            | Обмен с предложениями и подтверждением обеих сторон, группы, друзья, полноценные кланы, роли и репутация                                                                          |
| Новая графика мира            | Художественный стиль согласован на нескольких узнаваемых локациях; собственные модели всех типов существ, ресурсов и экипировки; эффекты, звук и LOD                              |
