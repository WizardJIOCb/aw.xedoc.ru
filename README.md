# AW · Возвращение на планету

Независимая фанатская реконструкция AWPlanet с новой браузерной 3D-сценой и видом от третьего лица. Первая играбельная альфа разворачивается на **https://aw.xedoc.ru**, сервер **82.146.42.213** (`ssh myserver`).

Это начальная область и собственная серверная реализация. Полного совпадения с оригиналом пока нет. Точные границы восстановления, источники и различия версий находятся в [docs/FIDELITY.md](docs/FIDELITY.md).

## Уже работает

- Регистрация, вход, общий мир через WebSocket, другие игроки и общий чат.
- Анимированный персонаж, камера от третьего лица, WASD, бег, движение к точке и столкновения с зданиями.
- Добыча ресурсов, 285 записей игрового каталога, 135 рецептов, 127 объектов начальной области.
- Профессии, параметры, PvE и ограниченный PvP, три режима боя и девять форс-режимов.
- Оружие и слоты брони, еда, добыча после боя, гибель с потерей вещей и части опыта.
- Банк, NPC-магазин, передача предметов, простые открытые кланы, собственное вводное задание Боба.
- Серверная проверка расстояний, скорости, требований, количества предметов и времени изготовления; атомарные сохранения, продолжение изготовления после перезапуска.

Формулы, баланс, цены, начальный район и ряд рецептов реконструированы. Наличие записи предмета в каталоге не означает восстановление каждого его особого эффекта. Передача предмета пока является подарком; двустороннего подтверждаемого обмена нет. Имена кланов пока не включают полноценное управление составом.

## Локальный запуск

Node.js 22 или новее, npm:

```powershell
npm ci
npm run dev:server
```

Во втором терминале:

```powershell
npm run dev
```

Открыть `http://127.0.0.1:5188`. API/WS: `127.0.0.1:3188`. Для единого production-сервера выполнить `npm run build`, затем `npm start`.

## Управление

WASD — движение; Shift — бег; перетаскивание мышью — камера; колесо — расстояние; двойной клик по земле или клик по мини-карте — идти к точке. E — ближайший объект; 1/пробел — атака; 2 — еда; I — инвентарь; C — ремёсла; K — персонаж; M — карта; B — общение; Enter — чат; Escape — закрыть окно.

Подойди к Бобу по кнопке задания. Добыча и торговля требуют близости. Для плавки нужен соответствующий станок; изготовление занимает указанное время. Ценные вещи можно оставить в банке перед вылазкой.

## Проверки

```powershell
npm run check
npm test
npm run build
node scripts/smoke.mjs http://127.0.0.1:3188
```

Smoke создаёт два тестовых аккаунта, выполняет обычные HTTP/WS-действия и выходит из них. Он не редактирует сохранения и не телепортирует персонажей. Отчёт записывается в `docs/QA.md`. Подробности браузерной проверки и публичного развёртывания — в `docs/DELIVERY.md`.

## Данные и модели

Официальный публичный пакет клиента исследуется парсером `scripts/import-reference.mjs`. Отдельный справочник `data/reference/` содержит 888 именованных объектов и 600 слотов взаимодействий. Это не 888 предметов и не готовая копия серверной базы. `data/build-world.py` воспроизводит игровой каталог.

Hero и Drone используют локально проверенные Quaternius CC0; дом, дерево и одежда доработаны собственным Blender-пайплайном. Лицензии и проверка анимаций — [docs/ASSETS.md](docs/ASSETS.md). Редактируемая сцена — `source-art/colony-assets.blend`. Оригинальная графика, клиентские исполняемые файлы и пользовательские сохранения в репозиторий не включены.
