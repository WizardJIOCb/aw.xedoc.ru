# Detailed colony replacements

The current `house.glb` and `tree.glb` are original project artwork authored in
Blender 5.1.1. They replace the early concept props while retaining their file
names, metre scale, ground origin and glTF Y-up orientation. Their style uses
light mineral plaster, dark roofing, petrol metal fittings and a human colony
worker palette. They are new artwork, not recovered original AWPlanet assets.

| --- | ---: | ---: | ---: | ---: |
| `house.glb` | 9,696 | 8 | 9 | 1,925,924 bytes |
| `tree.glb` | 3,936 | 2 | 3 | 558,804 bytes |

Primitive counts describe one normal colour pass. Shadow passes and additional
runtime effects add work. GPU performance with the full populated map must be
measured in the browser; these counts are asset measurements, not an FPS claim.

## Building

The house contains actual openings between wall sections, recessed glazing,
separate frames/mullions/sills, window hoods, five door planks and metal straps,
door handle, cyan controller/buttons, three stair treads, 64 individual roof
panels, gutters, downpipes, roof fascia/rafters, a ridge cap, exhaust stack,
rear service case/access panel/louvres, cables and a three-crossbar antenna.
Small exposed aggregate chips are geometry at the lower facade.

The nominal layout footprint remains 4.8 by 3.95 m. Steps, sills, gutters and
services extend beyond it. Full mesh bounds are 4.930 by 4.733 by 4.762 m in
X/Y/Z; roof wall ridge is 4.17 m and the antenna reaches 4.733 m. Facade is +Z.
Runtime collision should continue to use the layout footprint rather than the
decorative bounding box. The origin is at ground level in the footprint centre.

Eight materials are batched into one mesh, so the richer geometry does not
create hundreds of separate mesh submissions. There is no glTF transmission
material; recessed tinted opaque glass is used to keep the browser pass simple.

## Tree

The tree is a tapered curved trunk with five buttress roots, nine major branches,
eighteen smaller twigs and 430 individually shaped, folded leaf meshes. The
canopy has gaps and branch silhouettes; it contains no solid canopy sphere.
Leaves have per-vertex green variation and are opaque, double sided geometry.
There are only two material primitives. Bark UVs follow branch length.

Full bounds are X=3.188, Y=5.088, Z=2.555 m. Lowest root vertex is Y=-0.0092 m;
the top leaf is at 5.079 m. The origin is the trunk base. There are no tree
animation clips; wind, if desired, is a separate runtime shader effect.

## PBR source and provenance

All maps in `source-art/graphics-textures/` are generated by our authored
`scripts/build-graphics-assets.py` from deterministic value noise, trowel grain,
pinholes, streaks, bark ridges and height gradients. No downloaded image,
original AW artwork, stock photograph or external model enters these props.
They are original project-created artwork and have no third-party licence
dependency. No separate CC0 claim is made on behalf of the project owner.

Plaster uses 512px base colour, tangent normal and roughness maps. Bark and roof
use 256px equivalents. Base colour is sRGB; normal/roughness use Non-Color.
The glTF exporter packs roughness into the green channel of the metallic-
roughness image and leaves the material metallic factor explicit. Normal maps
connect through a Blender Normal Map node, with glTF `normalTexture.scale=0.5`.
All runtime images are embedded PNGs inside each GLB. No external image request
is needed. A 256px cloth normal is retained as optional original source art;
the hero file is not modified by this build.

## Bob

Bob derives from the existing licensed `hero.glb`, documented in `ASSETS.md`:
Quaternius standard character and retargeted Universal Animation Library are
CC0 1.0. The existing copied licence texts remain in `public/assets/licenses/`.
Our prior expedition garments and the new contoured gray beard, moustache,
sideburns, temple/rear hair and forehead work goggles are original project art.
The uniform is dark blue with an ochre work vest. Exposed lower-body/shoulder
polygons use cloth material; face/neck above the collar retain skin.

The beard/hair/goggles mesh is fully weighted to the existing Head joint. The
final file retains the original 65-joint skin and every original animation
accessor, channel and sampler without rebaking: `Idle`, `Walk`, `Run`, `Sprint`,
`Attack`, `Shoot`, `Hit`, `Death`, `Interact`. The hero file itself is unchanged.
Bob is approximately 1.84 m tall, faces +Z, and uses the same clone/mixer rules
as the hero. Use `SkeletonUtils.clone` for independent NPC instances.
The 14 material primitives cost more than a static prop; many distant humanoid
NPCs need culling/LOD rather than an assumption of free rendering.

## Reproduction and actual checks

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.1\blender.exe' --background --python .\scripts\build-graphics-assets.py -- --textures-only
& 'C:\Program Files\Blender Foundation\Blender 5.1\blender.exe' --background --python .\scripts\build-graphics-assets.py
& 'C:\Program Files\Blender Foundation\Blender 5.1\blender.exe' --background --python .\scripts\build-npc-bob.py
node .\scripts\validate-graphics-assets.mjs
```

Normal and roughness source PNGs were opened before final export. Each final GLB
was imported independently into Blender, rendered in Cycles and visually viewed:
`artifacts/graphics/colony-detailed-preview.png`, `house-detail-preview.png` and
`npc-bob-preview.png`. The corrected normal maps were also checked directly.

`artifacts/graphics/asset-validation.json` records Three.js GLTFLoader geometry
loading, finite attributes/bounds, PNG signatures, UVs, complete material maps,
budgets, and nine Bob clips sampled at five times each. Maximum sampled Bob
extent is 2.216 m in the Death animation, without an exploded rig. The validator
compares Bob's complete skins and animation JSON to the unchanged hero. Image
decoding is covered by the Blender render; the Node geometry check omits image
decoding because it has no browser canvas.

Editable sources are `source-art/colony-detailed.blend` and
`source-art/npc-bob.blend`. The earlier `colony-assets.blend` and `creatures.blend`
remain intact. Blender backup `.blend1` files and ignored `artifacts/` are kept
as local working evidence and need not be published. Browser integration and
deployment are separate checks performed by the scene owner.
